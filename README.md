# Quiet Chess

An ad-free local chess app. It runs entirely on your computer and does not load ads, trackers, or online assets.

## Open it

Double-click `index.html`, or run a small local server from this folder:

```sh
python3 -m http.server 8017
```

Then open:

```text
http://127.0.0.1:8017/index.html
```

## Features

- Play White against a simple local computer opponent
- Choose whether to play as White or Black
- Five difficulty levels: Beginner, Casual, Balanced, Strong, and Tough
- Hint button that suggests a move and highlights the board
- Coach panel with last-move feedback and material balance
- Last-move highlighting
- Two-player mode on the same board
- Legal move highlighting
- Check, checkmate, stalemate, castling, en passant, and promotion
- Undo, board flip, move list, and captured pieces
